Finite State Machine for Smart Parking

An interactive simulation of a smart parking system using Finite State Machine concepts.

FSM States

S0 - Empty

No vehicles are parked.

S1 - Detected

Vehicle is detected.

S2 - Occupied

Parking slots are occupied.

S3 - Full

All parking slots are full.
